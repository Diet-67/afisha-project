# 🎭 Afisha Project

Аналитический проект, посвящённый исследованию пользовательской активности и посещаемости мероприятий.  
Цель — выявить закономерности, подготовить рекомендации и визуализировать ключевые метрики.

---

## 📌 Цели проекта
- Провести исследовательский анализ данных (EDA)  
- Очистить и подготовить данные  
- Проверить статистические гипотезы  
- Построить визуализации  
- Сформировать выводы и рекомендации  

---

├── .gitignore                 # исключения для Git

## 🚀 Как запустить проект

### 1. Клонировать репозиторий

git clone https://github.com/Diet-67/afisha-project.git (github.com in Bing)
cd afisha-project

### 2. Установить зависимости
pip install -r requirements.txt

### 3. Создать файл окружения

Скопируйте `.env.example` → `.env`:
cp .env.example .env
